# SV Bakede – Website-Editor (Testversion)

Programm für Windows, mit dem die Website des Schützenvereins Bakede bearbeitet wird:
Termine, Beiträge, Personen, Seiten und Fotos ändern, das Ergebnis sofort in der Vorschau sehen
und später mit einem Klick veröffentlichen.

**Das ist eine Testversion.** Zum Ausprobieren ist alles erlaubt: An der echten Website ändert sich
dabei nichts.

## Herunterladen

Unter **[Releases](../../releases)** die oberste (neueste) Version öffnen und dort herunterladen:

| Datei | Wofür |
|---|---|
| `SV-Bakede-Website-Editor_…_Setup.exe` | Das Programm (Installation, ca. 2 MB) |
| `SV-Bakede-Website-aktueller-Stand.zip` | Die Website im aktuellen Stand zum Anschauen im Browser (optional) |

## Installieren

1. Die `…_Setup.exe` doppelklicken.
2. Windows zeigt eventuell **„Der Computer wurde durch Windows geschützt“**, weil das Programm neu ist und
   nicht von einer großen Firma stammt. Dann auf **„Weitere Informationen“** und danach auf
   **„Trotzdem ausführen“** klicken.
3. Den Schritten des Installationsprogramms folgen. Administratorrechte sind nicht nötig.
4. Danach steht **„SV Bakede Website“** im Startmenü und auf dem Desktop.

Benötigt wird Windows 10 oder 11. Weitere Programme muss man nicht installieren.

## Was in der Testversion geht

- Alle Seiten und zentralen Inhalte bearbeiten (Termine, Beiträge, Hinweisleiste, Personen, Majestäten,
  Trainingszeiten, Seiten und Menü), Fotos vom Computer einfügen, neue Seiten anlegen.
- Rechts die **Vorschau**: So würde die Website aussehen. Mit **„Handy“** sieht man die Handy-Ansicht,
  mit **„⌖ Wo bearbeiten?“** zeigt das Programm, wo man einen Teil der Seite ändert.
- Alles wird automatisch auf diesem PC gespeichert.

**Veröffentlichen geht in der Testversion noch nicht**, weil dafür der Server-Zugang fehlt. Ein Klick auf
„Veröffentlichen“ öffnet nur die Seite „Server-Zugang“. Die kann man in der Testversion einfach
überspringen und links eine andere Seite wählen.

## Neue Versionen

Ab Version 0.1.2 steht unten links im Programm **„Updates suchen“**. Ein Klick prüft, ob es eine neue
Version gibt, und installiert sie auf Wunsch. Das Programm schließt sich dabei kurz und startet von selbst
neu, alle Änderungen bleiben erhalten. Wird gerade keine neue Version angeboten, meldet das Programm das.

Wer noch Version 0.1.0 oder 0.1.1 hat, installiert 0.1.2 einmal von Hand (wie oben beschrieben, die alte
Version wird dabei ersetzt). Danach geht es über den Knopf.

## Website im aktuellen Stand ansehen (optional)

Die ZIP-Datei entpacken (Rechtsklick → „Alle extrahieren“) und im Ordner `index.html` doppelklicken.
So sieht man die Website ohne Änderungen und kann sie mit der Vorschau im Programm vergleichen.
Fotos und Schrift kommen aus dem Internet.

## Entfernen

Windows-Einstellungen → Apps → Installierte Apps → „SV Bakede Website“ → Deinstallieren.
